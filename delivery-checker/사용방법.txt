도로대장 납품 검수 프로그램
==========================

납품 폴더(또는 ZIP)를 서버에 올리기 전에, 이 PC에서 미리 검사하는 프로그램입니다.
서버 연결·로그인·DB가 필요 없고, 검사하는 파일은 이 PC 밖으로 나가지 않습니다.
서버의 "일괄등록 > 검수"와 같은 코드로 검사하므로, 여기서 나온 결과가 서버 검수와 같습니다.

[사용 순서]
1. "검수프로그램.bat"을 더블클릭합니다. 검은 창이 뜨고 브라우저에 검수 화면이 열립니다.
   (검은 창을 닫으면 프로그램이 종료됩니다. 검수하는 동안은 닫지 마세요.)
2. [폴더 선택] 또는 [ZIP 선택]으로 납품을 고릅니다. (선택 창이 브라우저 뒤에 열리면 작업 표시줄에서 찾으세요.
   창이 안 열리는 PC에서는 폴더/ZIP의 경로를 입력칸에 직접 붙여넣어도 됩니다 — 탐색기 주소창을 복사하거나,
   ZIP 파일을 Shift+우클릭 → "경로로 복사".)
   - 폴더: 관리번호 폴더(예: 415902026101001)들이 들어 있는 상위 폴더를 고릅니다.
   - ZIP: 납품을 압축한 파일을 고릅니다. 용량이 크면(1GB 이상) 푸는 데 30초~몇 분 걸립니다.
3. [검수 시작]을 누릅니다.
4. 결과를 확인합니다.
   - 맨 위 색깔 상자가 종합 판정입니다.
       초록: 문제 없음 / 노랑: 등록은 되지만 확인할 항목 있음 / 빨강: 등록 안 되거나 일부가 빠지는 문제 있음
   - [결함 목록 CSV 내려받기]: KRRIS 지적 대상(좌표계, 필수항목 빈 값)의 전체 목록입니다.
     파일명과 행 번호가 있어서 QGIS 등에서 바로 찾을 수 있습니다. 납품 업체에 그대로 전달하세요.
   - [결과 인쇄/PDF 저장]: 화면 그대로 인쇄하거나 PDF로 저장합니다.

[검사하는 항목]
- 레이어 파일(DBF/SHP): 레이어별 신규/삭제 건수, 좌표계(KRRIS 기준 EPSG:5179), 필드 구성,
  필수 필드 누락, 다른 레이어의 속성표가 잘못 들어간 파일
- KRRIS 사전검사: 좌표계(C-1), 필수항목 빈 값(M-1)
- 사진·보고서(PHOTO/STR): 파일명이 시설물 ID와 같아 자동 연결되는지
- 도면: ETC 폴더 도면, 구간 도면(500_P/500_Y/500_U, CONT)의 파일명으로 노선·구간이 인식되는지
- 500m 구간 SHP: 관리번호 폴더 바로 아래의 {도로종류}{노선번호}.shp(예: 면도0101.shp)가 읽히는지
- 도로종류: 500m 구간 SHP 파일명에서 읽은 면도/리도/농도 구분

[알아 둘 점]
- 이 프로그램은 검사만 합니다. 서버에 등록하거나 파일을 바꾸지 않습니다.
- 검사 기준(시설물 테이블 구성)은 프로그램을 만든 시점의 서버 스키마입니다. 서버 스키마가 바뀌면
  새 버전을 받아서 쓰세요(화면 맨 아래에 기준 날짜가 표시됩니다).
- ZIP은 임시 폴더에 풀어서 검사한 뒤 바로 지웁니다.
- 이 화면은 이 PC에서만 열립니다(같은 네트워크의 다른 PC에서는 접속할 수 없습니다).
- 포트 8765가 사용 중이면 8766, 8767…을 자동으로 씁니다. 검은 창에 표시된 주소로 접속하세요.

[만드는 방법 — 개발자용]
  node delivery-checker/build-schema-snapshot.js     (server 폴더에서 실행, DB 접속 필요: 테이블 구성 갱신)
  node delivery-checker/build-portable.js --zip      (delivery-checker/dist/ 에 폴더와 ZIP 생성)
