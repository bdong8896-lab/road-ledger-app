========================================================
 도로대장 시스템 — 설치 없는 로컬 실행 (포터블)
========================================================
이 폴더 하나로 실행됩니다. Docker, Node.js, PostgreSQL 을 따로 설치하지 않아도 되고,
관리자 권한도 필요 없습니다. (Windows 10/11 64비트)

[처음 한 번]
 1. ZIP 을 원하는 위치에 풉니다.  예) D:\RoadLedger-Local   또는 내 문서 안
      - 경로에 한글·공백이 없으면 가장 안전합니다. 바탕화면이나 OneDrive 폴더는 피하세요(동기화로 DB 파일이 깨질 수 있음).
      - 쓰기가 가능한 위치여야 합니다(Program Files 는 안 됨).
      - 사용자 이름이나 폴더 이름이 한글이어도 됩니다(자동으로 영문 가상 드라이브 R:~Z: 중 빈 문자를 잠깐 연결해 DB 를 실행하고, 끝나면 해제합니다).
 2. start.bat 을 더블클릭합니다. (마우스 오른쪽 "관리자 권한으로 실행"은 하지 마세요 — PostgreSQL 이 거부합니다)
 3. 처음에는 DB 를 만드느라 1~2분 걸립니다. 중간에 아래 두 가지를 묻습니다.
      - VWorld 지도 키: 이 PC 용으로 발급받은 키(서비스 URL: http://localhost). 지금 없으면 Enter.
      - 관리자 아이디/비밀번호(8자 이상)
 4. 끝나면 브라우저가 자동으로 열립니다. 안 열리면 검은 창에 표시된 주소(예: http://localhost:8080)로 접속하세요.

[평소 사용]
 - 켜기: start.bat 더블클릭 (DB + 서버 + 브라우저가 한 번에)
 - 끄기: 검은 창에서 Ctrl+C  (DB 도 함께 꺼집니다)
 - 검은 창을 그냥 닫았다면: stop.bat 으로 DB 를 끄세요(안 꺼도 다음 start.bat 때 이어서 쓰므로 큰 문제는 아닙니다).
 - 백업: backup.bat  →  data\backups\날짜_시각\ (DB 덤프 + 업로드 파일)

[폴더 구성]
 start.bat / stop.bat / backup.bat / restore.bat   실행 파일
 app\       서버·화면 프로그램 (업데이트 때 이 폴더만 교체). 화면(public-dist)은 난독화된 파일입니다.
 pg\        PostgreSQL 프로그램
 runtime\   Node.js
 data\      내 자료(DB, 업로드 파일, 백업) — 처음 실행 때 생김. 이 폴더가 "내 데이터"이니 지우지 마세요.

[VWorld 지도 키]
 지도가 안 보이면 키 문제입니다. 키는 서비스 URL 에 잠겨 있어 다른 PC·서버용 키는 안 됩니다.
 https://www.vworld.kr 에서 서비스 URL http://localhost 로 새로 발급받아
 app\server\.env 의 VWORLD_API_KEY= 뒤에 붙여 넣고 start.bat 을 다시 실행하세요.
 (지도 타일과 화면 라이브러리는 인터넷에서 불러오므로, 인터넷이 막힌 PC 에서는 지도가 보이지 않습니다.)

[문제 해결]
 - "관리자 권한으로 실행되어 있습니다": 관리자 권한 없이 그냥 더블클릭하세요.
 - "포트가 사용 중": 이미 실행 중인 검은 창이 있는지 확인하세요. 다른 프로그램이 쓰는 경우 app\server\.env 의 PORT 를 바꾸세요.
 - 보안 프로그램이 파일을 지우거나 실행을 막는 경우: 이 폴더를 예외로 등록하도록 보안 담당자에게 요청해야 합니다.
 - 처음부터 다시: data 폴더와 app\server\.env 를 지우고 start.bat (자료가 모두 사라집니다).
 - "가상 드라이브를 만들지 못했습니다": 이 폴더를 한글이 없는 경로(예: D:\RoadLedger-Local)로 옮기면 됩니다.
 - 로그: data\pg.log (DB)

[다른 PC 로 옮기기 / 복원 / 업데이트]
 - 자료까지 옮기기:
     1) 원래 PC 에서 backup.bat → dataackups\날짜_시각 폴더가 생김. 이 폴더를 새 PC 로 복사.
     2) 새 PC 에서 ZIP 을 풀고 start.bat 을 한 번 실행(DB 가 만들어짐, 관리자 계정은 아무거나) 후 Ctrl+C 로 끔.
     3) restore.bat "복사한 백업 폴더 경로"  → YES 입력. (이후 로그인은 원래 PC 의 계정으로)
      (DB 에 저장된 파일 경로는 복원할 때 이 폴더 기준으로 자동 보정됩니다.)
 - 같은 PC 에서 이전 백업으로 되돌릴 때도 restore.bat 을 씁니다(서버를 먼저 끄세요).
 - 프로그램 업데이트: 새 ZIP 의 app 폴더로 기존 app 폴더를 바꾸되, app\server\.env 는 그대로 둡니다. data 는 건드리지 않습니다.
