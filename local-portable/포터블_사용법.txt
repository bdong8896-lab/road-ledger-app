========================================================
 도로대장 시스템 — 설치 없는 로컬 실행 (포터블)
========================================================
이 폴더 하나로 실행됩니다. Docker, Node.js, PostgreSQL 을 따로 설치하지 않아도 되고,
관리자 권한도 필요 없습니다. (Windows 10/11 64비트)

[처음 한 번]
 1. ZIP 을 원하는 위치에 풉니다.  예) D:\RoadLedger-Local   또는 내 문서 안
      - 바탕화면이나 OneDrive 폴더는 피하세요(동기화로 DB 파일이 깨질 수 있음). 쓰기가 가능한 위치여야 합니다(Program Files 는 안 됨).
      - 사용자 이름이나 폴더 이름이 한글이어도 됩니다(자동으로 영문 가상 드라이브 R:~Z: 중 빈 문자를 잠깐 연결해 DB 를 실행하고, 끝나면 해제합니다).
 2. RoadLedger.exe 를 더블클릭합니다. (마우스 오른쪽 "관리자 권한으로 실행"은 하지 마세요 — PostgreSQL 이 거부합니다)
      - 처음 열 때 Windows 가 "인터넷에서 받은 파일" 경고를 띄우면 "추가 정보 → 실행"을 누르세요.
 3. 창이 뜨면 [▶ 서버 시작]을 누릅니다. 처음에는 데이터베이스를 만드느라 1~2분 걸립니다.
      - 이 패키지에는 VWorld 지도 키와 기본 관리자 계정이 들어 있어 아무것도 묻지 않습니다.
      - 기본 관리자 계정: 아이디 admin / 비밀번호 1234  (이 PC 안에서만 접속되는 로컬 실행용입니다. 다른 사람과 쓰거나 실제 자료를 올리기 전에 비밀번호를 바꾸세요.)
      - 키·계정이 들어 있지 않은 패키지라면 중간에 입력창이 떠서 VWorld 키와 관리자 아이디/비밀번호(8자 이상)를 묻습니다.
 4. 준비가 끝나면 상태가 "서버가 실행 중입니다"로 바뀌고 브라우저가 자동으로 열립니다. 안 열리면 [브라우저에서 열기]를 누르세요.

[창의 버튼]
 ▶ 서버 시작        데이터베이스와 서버를 켭니다.
 ■ 서버 종료        서버를 끄고 데이터베이스를 안전하게 닫습니다.
 브라우저에서 열기   실행 중일 때 시스템 화면(http://localhost:포트)을 엽니다.
 백업               DB 덤프 + 업로드 파일을 data\backups\날짜_시각\ 에 저장합니다(서버가 켜진 채로 가능).
 복원               백업 폴더를 고르면 그 시점으로 되돌립니다(서버를 먼저 끄세요. 지금 자료는 덮어써집니다).
 자료 폴더 열기      data 폴더(내 자료)를 탐색기로 엽니다.
 프로그램 종료       서버를 끄고 창을 닫습니다.
 - 창의 X 버튼: 서버가 켜져 있으면 "서버를 종료하고 닫기 / 서버는 계속 실행하고 창만 닫기 / 취소"를 묻습니다.
   창만 닫았다면 RoadLedger.exe 를 다시 열면 실행 중으로 이어서 보이고, 거기서 종료할 수 있습니다.
 - 상태 표시: 회색 = 중지됨, 노랑 = 시작/종료/백업 중, 초록 = 실행 중.

[폴더 구성]
 RoadLedger.exe  실행 파일(이것만 열면 됩니다)
 README.txt      이 문서
 app\            서버·화면 프로그램 (업데이트 때 이 폴더만 교체). 화면(public-dist)은 난독화된 파일입니다.
 pg\             PostgreSQL 프로그램
 runtime\        Node.js
 scripts\        실행 관리 창과 내부 스크립트(수정하지 마세요)
 tools\          문제 해결용 콘솔 실행 파일(start/stop/backup/restore .bat) — 평소에는 쓰지 않습니다.
 data\           내 자료(DB, 업로드 파일, 백업) — 처음 실행 때 생김. 이 폴더가 "내 데이터"이니 지우지 마세요.

[VWorld 지도 키]
 이 패키지에는 키가 내장되어 있습니다(서비스 URL http://localhost 로 등록된 키). 다른 키로 바꾸려면 아래처럼 하세요.
 지도가 안 보이면 키 문제입니다. 키는 서비스 URL 에 잠겨 있어 다른 PC·서버용 키는 안 됩니다.
 https://www.vworld.kr 에서 서비스 URL http://localhost 로 새로 발급받아
 app\server\.env 의 VWORLD_API_KEY= 뒤에 붙여 넣고 서버를 다시 시작하세요.
 (지도 타일과 화면 라이브러리는 인터넷에서 불러오므로, 인터넷이 막힌 PC 에서는 지도가 보이지 않습니다.)

[문제 해결]
 - 창이 열리지 않거나 바로 닫힘: 보안 프로그램이 RoadLedger.exe 나 PowerShell 실행을 막은 경우입니다.
   이 폴더를 예외로 등록하도록 보안 담당자에게 요청하세요. 급하면 tools\start.bat 로 콘솔에서 실행해 오류 메시지를 볼 수 있습니다.
 - "이미 실행 중입니다": 같은 폴더의 창이 이미 열려 있습니다. 작업 표시줄을 확인하세요.
 - "관리자 권한으로 실행되어 있습니다": 관리자 권한 없이 그냥 더블클릭하세요.
 - "포트가 사용 중": 이미 서버가 켜져 있는지 확인하세요. 다른 프로그램이 쓰는 경우 app\server\.env 의 PORT 를 바꾸세요.
 - 서버를 시작하지 못했다는 안내가 뜨면: 창의 '진행 상황'과 data\server.out.log, DB 문제는 data\pg.log 를 확인하세요.
 - "가상 드라이브를 만들지 못했습니다": 이 폴더를 한글이 없는 경로(예: D:\RoadLedger-Local)로 옮기면 됩니다.
 - 처음부터 다시: 서버를 끄고 data 폴더와 app\server\.env 를 지운 뒤 다시 시작(자료가 모두 사라집니다).

[다른 PC 로 옮기기 / 복원 / 업데이트]
 - 자료까지 옮기기:
     1) 원래 PC 에서 [백업] → data\backups\날짜_시각 폴더가 생김. 이 폴더를 새 PC 로 복사.
     2) 새 PC 에서 ZIP 을 풀고 [서버 시작]으로 한 번 실행(DB 가 만들어짐) 후 [서버 종료].
     3) [복원] → 복사한 백업 폴더를 선택 → 확인. (이후 로그인은 원래 PC 의 계정으로)
      (DB 에 저장된 파일 경로는 복원할 때 이 폴더 기준으로 자동 보정됩니다.)
 - 프로그램 업데이트: 새 ZIP 의 app 폴더(와 scripts, RoadLedger.exe)로 기존 것을 바꾸되, app\server\.env 는 그대로 둡니다. data 는 건드리지 않습니다.
