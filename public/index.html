관리 콘솔
국토부 표준 SHP/DBF 납품 폴더(관리번호 폴더)를 ZIP으로 압축하거나, 압축 없이 폴더째로 업로드하세요. 사진·보고서·도면은 SFTP로 서버(bulk-import-incoming)에 같은 이름의 폴더로 미리 올려두면 자동으로 연동됩니다.
여기로 ZIP 파일을 끌어다 놓거나
클릭하여 선택하세요
또는
SFTP로 서버(bulk-import-incoming)에 미리 올려둔 납품 폴더(LAYER/신규 포함 전체) 또는 ZIP 파일을 골라 검수합니다. ZIP은 서버에서 풀어 검수하며 원본 ZIP은 지우지 않습니다. 하나만 선택하면 검수 화면에서 확인 후 등록, 여러 개를 고르거나 전체 등록을 누르면 시군구 하나로 순서대로 자동 등록됩니다.
도면 파일(dwg/dxf) 또는 ZIP을 올리면 파일명(예: 000801100500P.dwg, TOP000801.dxf)에서 노선번호·구간번호를 읽어 이미 등록된 해당 구간에 자동으로 붙입니다. 대상 노선을 따로 고르지 않아도 됩니다. 노선을 고르면 그 노선 구간에만 붙이며, 이때는 ZIP 1개만 올릴 수 있습니다(예: CON080001.dxf처럼 이름에 노선번호가 없는 옛 형식).
여기로 도면(dwg/dxf) 또는 ZIP 파일을 끌어다 놓거나
클릭하여 선택하세요(여러 개 가능)
